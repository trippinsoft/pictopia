# Pictopia branding

The user-supplied stacked-photo icon is the source for the opaque app icon, padded Android adaptive foreground and browser favicon. The outer black canvas of the source is filled white so the operating system can apply its own icon mask. Android notifications use a monochrome version of the same stacked-photo mark.

The supplied portrait splash is used on iOS, fitted to the available screen so the tagline remains visible in landscape. Android uses the stacked-photo symbol from that artwork on white, sized for the system splash mask.
